# ⚽ Ομάδα – Διαχείριση ποδοσφαιρικής ακαδημίας

Web app (PWA) για τη διαχείριση συλλόγου: παίκτες, ομάδες, χρεώσεις, πληρωμές, PDF, email, αρχεία, αγώνες και στατιστικά.
Τρέχει σε κινητό, tablet και υπολογιστή, εγκαθίσταται στην αρχική οθόνη, και είναι έτοιμο να τυλιχτεί με Capacitor για Play Store / App Store.

## Λειτουργίες
- **Παίκτες**: πλήρες προφίλ, κηδεμόνες, ΑΜΚΑ, κάρτα υγείας με ειδοποίηση λήξης, φωτογραφία, αδέρφια (κωδικός οικογένειας)
- **Αρχεία**: ανέβασμα ιατρικών, ταυτοτήτων, υπεύθυνων δηλώσεων, φωτογραφιών (ιδιωτική αποθήκευση)
- **Ομάδες**: τμήματα, προπονητής, πρόγραμμα, συνδρομή ανά ομάδα, ανάθεση παικτών, ομαδικό email σε γονείς
- **Χρεώσεις**: αυτόματες μηνιαίες συνδρομές (κάθε μήνα στη μέρα που ορίζεις), εκπτώσεις & έκπτωση αδερφών, έκτακτες χρεώσεις, μερικές πληρωμές
- **PDF**: κατάσταση χρεώσεων με λογότυπο/IBAN, λήψη ή αποστολή με email· μαζικές υπενθυμίσεις οφειλών
- **Αγώνες/Προπονήσεις**: πρόγραμμα, σκορ, παρουσίες, γκολ, ασίστ, κάρτες, λεπτά, πίνακας κορυφαίων
- **Χρήστες**: ο πρώτος λογαριασμός είναι διαχειριστής· προπονητές εγκρίνονται από τις Ρυθμίσεις

## Τεχνολογία
React + Vite + TypeScript, Supabase (Postgres, Auth, Storage, Edge Functions, pg_cron), jsPDF, Resend για email.

## Email
Στο Supabase → Edge Functions → Secrets: `RESEND_API_KEY` και `MAIL_FROM` (π.χ. `Ακαδημία <info@το-domain-σου.gr>`).

## Τοπικά
```
npm install
npm run dev
```
